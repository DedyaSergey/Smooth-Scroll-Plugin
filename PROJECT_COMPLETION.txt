🚀 QUICK START
═════════════════════════════════════════════════════════════════════════════════

Step 1: Clone Repository
$ git clone https://github.com/DedyaSergey/Smooth-Scroll-Plugin.git

Step 2: Copy Plugin
Copy src/SmoothScroll.plugin to:
  Ayugram/plugins/SmoothScroll.plugin

Step 3: Restart Ayugram
Force close and reopen the app

Step 4: Enable Plugin
Settings → Plugins → Smooth Chat Scroll Pro → Toggle ON

Step 5: Access Settings
Click the Settings button next to the plugin to configure:
  • Animation style (8 options)
  • Speed (Slow/Normal/Fast)
  • FPS (30/60/120)
  • Gestures (Enable/Disable)
  • And 11+ more options

Step 6: Test
Send any of these commands in a chat:
  .scroll.test ............ Test smooth scrolling
  .scroll.gesture ........ Test gestures
  .scroll.stats .......... Performance stats
  .scroll.info ........... Plugin info
