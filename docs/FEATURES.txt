├─ Direction: ← (horizontal)
├─ Animation: OutCubic (fast)
├─ Use case: Navigate to next chat

├─ Direction: → (horizontal)
├─ Animation: OutCubic (fast)
├─ Use case: Navigate to previous chat
└─ Visual: Slide effect

SWIPE UP
├─ Direction: ↑ (vertical)
├─ Animation: OutCubic (fast)
├─ Use case: Scroll up in chat
└─ Visual: Push up effect

SWIPE DOWN
├─ Direction: ↓ (vertical)
├─ Animation: OutCubic (fast)
├─ Use case: Scroll down in chat
└─ Visual: Push down effect

PINCH ZOOM
├─ Gesture: Two finger pinch
├─ Animation: InOutCubic (250ms)
├─ Use case: Zoom in/out on content
└─ Visual: Scale effect

LONG PRESS
├─ Gesture: Sustained touch (500ms+)
├─ Animation: InOutCubic (200ms)
├─ Use case: Open context menu
└─ Visual: Pulse effect

  13. transition_duration ....... Transition speed

Debug Settings:
  14. debug_mode ................ Show debug logs
  15. statistics_tracking ....... Frame statistics ON/OFF
