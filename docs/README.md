# 🎨 Smooth Chat Scroll Pro v2.0

**Профессиональный плагин для Ayugram** с плавными анимациями, поддержкой жестов и оптимизированной производительностью.

---

## ✨ Основные возможности

### 🎬 **8+ стилей анимаций**
- **Smooth** - Классическая гладкая анимация (Cubic Ease-In-Out)
- **Elastic** - Эластичная, пружинящая анимация
- **Ease Out** - Замедление в конце
- **Bounce** - Отскок с отскочиваниями
- **Spring** - Пружинистая анимация
- **Wave** - Волнистая синусоидная функция
- **Bezier** - Кубическая кривая Безье
- **Decelerate** - Плавное замедление

### 👆 **Поддержка жестов**
- Свайп влево/вправо/вверх/вниз с анимациями
- Пинч-зум анимация
- Долгое нажатие с визуальной обратной связью
- Инерция прокрутки после отпускания

### ⚙️ **Оптимизация производительности**
- Ограничение FPS (30/60/120 FPS)
- Пропуск кадров при необходимости
- Мониторинг производительности в реальном времени
- Поддержка GPU ускорения
- Снижение нагрузки на батарею

### 📊 **Переходы между чатами**
- Плавный fade (затухание)
- Slide (скольжение)
- Scale (масштабирование)

---

## 📥 Установка

1. Скопируйте файл `SmoothScroll.plugin` в папку плагинов Ayugram
2. Перезагрузите приложение
3. Включите плагин в настройках

**Требования:**
- Ayugram >= 12.5.0
- SDK >= 1.4.0

## 🎨 Easing функции (математическое обоснование)

### Cubic In-Out (Smooth)
- **Формула:** `t < 0.5 ? 4t³ : 1 - (-2t+2)³/2`
- **Применение:** Идеален для общих анимаций прокрутки
- **Характеристика:** Ускорение в начале, замедление в конце

### Elastic (Пружина)
- **Формула:** `2^(-10t) * sin((10t - 0.75) * π * 2 / 3) + 1`
- **Применение:** Интересные, живые анимации
- **Характеристика:** Пульсирующий эффект

### Spring (Пружинистая)
- **Формула:** Модифицированная elastic для более мягкого эффекта
- **Применение:** Нежные пружинящие переходы
- **Характеристика:** Меньше колебаний чем elastic

### Wave (Волна)
- **Формула:** `0.5 - 0.5 * cos(π * t)`
- **Применение:** Синусоидальные, волнообразные движения
- **Характеристика:** Плавное периодическое движение

### Bezier (Кубическая кривая)
- **Формула:** Кубическая кривая Безье с контрольными точками
- **Применение:** Премиум-подобные анимации
- **Характеристика:** Гладкая, контролируемая кривая

## 🚀 Оптимизация производительности

### PerformanceMonitor
Автоматически мониторит и контролирует количество кадров в секунду:

```python
- Максимум 120 FPS для плавности
- Стандарт 60 FPS для баланса
- Экономия 30 FPS для снижения нагрузки
```

### Пропуск кадров
Плагин умно пропускает кадры если GPU занят, сохраняя плавность.

### Статистика
Отслеживает:
- Общее количество отрисованных кадров
- Количество пропущенных кадров
- Процент успешной отрисовки
- Текущие настройки анимации

```
2. Введите `.scroll.stats`

4. Если меньше - снизьте FPS или отключите жесты
```

## 🐛 Поиск и устранение проблем

### Прокрутка не плавная
- Попробуйте снизить максимальный FPS (60 → 30)
- Отключите "Аппаратное ускорение"
- Проверьте `.scroll.stats` - коэффициент рендера должен быть > 90%

### Батарея быстро разряжается
- Включите "Оптимизация FPS"
- Установите "30 FPS (экономно)"
- Отключите ненужные жесты

### Жесты не работают
- Убедитесь что включена опция "Анимации жестов"
- Введите `.scroll.gesture` для теста
- Проверьте версию Ayugram (должна быть >= 12.5.0)

### Анимация зависает
- Введите `.scroll.test` для диагностики
- Проверьте `.scroll.stats` - если пропускается > 10% кадров, снизьте FPS
- Перезагрузите приложение

## 💡 Советы для лучшей производительности

1. **Используйте Smooth или Bezier** для ежедневного использования - они легче для GPU
2. **Жесты работают лучше** при 60+ FPS - не устанавливайте 30 FPS если используете жесты
3. **Тестируйте на вашем устройстве** с помощью `.scroll.stats` перед критическим использованием
4. **Wave хорошо работает** для переходов между чатами, а не для прокрутки
5. **Elastic требует больше ресурсов** - используйте только если нужен эффект пружины
